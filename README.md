# ぷにっかー -日本縦断編-（Unity版・制作中）

もちすけをタップして「もち」を増やし、おみやげで強化しながら、47都道府県を旅するクリッカーゲームです。
個人制作（1人）で、2026年6月から制作しています(Unity版は10月から)。

- 遊べる版（JS版・試作）：https://mochamochatv.github.io/mochisuke-clicker/
- このリポジトリ：JS版を参考に、**自分で理解しながらUnityで作り直している版**です（完成度 約10%）

## なぜ作り直しているか
JS版は生成AIにコードを書かせた試作で、早く遊べる形にはなりましたが、中身を理解できず、直し方や機能の追加を自分で考えられませんでした。
また、プレイ中に数値を調整できず、調整のたびにブラウザを開き直す必要がありました。
そこで、自分で説明できるコードにするために、Unityで一つずつ理解しながら作り直しています。

## 実装済み
- タップでもちが増える／押した場所に「+〇 もち」が浮かぶ
- 自動でもちが増える（放置収入）
- おみやげの棚（9マス×ページ）と購入・レベルアップ
- 47都道府県の旅の進行（背景・県名の切り替え）
- セーブ／ロード（一定時間ごとに自動保存）

## 設計で工夫したこと
- **役割ごとにファイルを分ける**：もち数（MochiWallet）、旅の進行（StageProgress）、おみやげ（OmiyageShop）、タップ（MochisukeTap）、演出（TapEffects / FloatingText）、保存（SaveManager）など
- **データとプログラムを分ける**：47ステージの名前・値段・画像・日記は `StageDatabase.asset`（ScriptableObject）にまとめ、プログラムを触らずにInspectorで編集できる
- **調整しやすくする**：調整の機会が多い値は `[SerializeField]` と `[Header]` でInspectorにまとめ、プレイ中に数値を変えて試せる
- **大きな数を扱う**：もち数は億・兆まで増えるため `double` で持ち、表示だけ `MochiFormat.cs` で「1.250000億」のような単位付きの文字に直す
- **連打対策**：浮かぶ文字は同時に40個までに制限
- **読みやすさ**：ほかのファイルの値や関数を使う行には、どのファイルの何を呼んでいるかをコメントで書いている

## どこから読むか
1. `Assets/Scripts/MochisukeTap.cs`：タップした時に何が起きるか（入口）
2. `Assets/Scripts/MochiWallet.cs` / `StageProgress.cs` / `OmiyageShop.cs`：数を持つ・計算する部分
3. `Assets/Scripts/Data/StageDatabase.cs`：ステージデータの形
4. `Docs/punicker_structure.drawio`：スクリプト同士のつながりの図（draw.ioで開けます）

## 生成AIの使い方
- JS版：コードはClaudeが実装。企画・仕様の指示・数値調整・テストプレイでの検証は自分で担当
- Unity版：機能ごとに区切ってAIに教わり、質問を繰り返し、処理の意味を理解してから自分で実装・調整
- 画像素材：ChatGPT、MiriCanvasで生成
